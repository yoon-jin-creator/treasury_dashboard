연도실현손익배당·이자평가손익당기손익상세
당기손익 = 실현손익(처분이익−처분손실) + 배당·이자 + 평가손익. 실현은 처분 거래처원장, 배당·이자는 재무제표(22~29기)·30기는 회계전표(07-31) 정본. 평가손익은 단기투자자산평가익(905)·평가손(937) 계정(분기·기말 시가, 익월 반제)으로 25~29기 반영, 30기는 29기말 미실현 대비 현재가 실시간 추정(). 미실현은 단기매매 주식만 — 만기보유 채권(EBRD 등)은 상각후원가라 제외. 22~24기(▪)는 매도가능증권 시대라 평가손익이 자본(기타포괄손익)으로 가 당기손익 제외(23기 −4.05억/24기 +6.07억은 자본), 처분차익도 자본 경유 — 표의 실현은 경제적 처분차익입니다. 25기부터 단기매매증권(FVPL)로 손익 반영.
상단 [보기]로 종목별(계좌 합산·클릭 시 증권사 분해)과 증권사별(계좌 묶음·하단 매매실적 포함)을 전환합니다. 보유수량은 HTS 투자현황(2026-08-18), 현재가·평가금액은 전일 종가(2026-08-21)로 매일 갱신됩니다. 평균매입가는 회계(위)·HTS(아래) 동시 표시 — 회계는 종목 통합, HTS는 계좌별. [단가·손익 기준] 토글은 매입금액·평가손익·수익률을 회계장부/HTS로 전환합니다. 평가손익 막대는 0 기준 +우측·−좌측.
보기 증권사 유형 단가·손익 기준
평가금액·현재가·보유수량은 HTS 시가 기준. 회계장부 기준 선택 시 평균매입가·매입금액=회계 이동평균 취득원가, 평가손익=시가−회계원가. ˢ 표시(만기보유 채권 등)는 회계상 평가손익 미인식(상각후원가)이라 회계 평가손익 0으로 처리 — 그래서 회계 평가손익(−7.97억)이 HTS(−0.20억)와 다릅니다. 증권사 구분은 HTS 계좌 기준(회계장부는 증권사 미구분).
